# Guía visual

Identidad: **TurnosYa!**. En el logo, la "o" es una pelota de fútbol.

## Colores (`src/theme/colores.ts`)
| Token | Hex | Uso |
| --- | --- | --- |
| primario | #1B7A3E | verde cancha: botones, tabs activos |
| primarioOscuro | #145C2E | botón presionado |
| acento | #F5C518 | destacados, badges |
| fondo | #F7F9F7 | fondo de pantallas |
| superficie | #FFFFFF | tarjetas, campos |
| texto | #1A1F1C | texto principal |
| textoSuave | #5F6B64 | texto secundario |
| borde | #DDE3DF | bordes y separadores |

| error | #C62828 | errores y cancelar |
| fondoModal | #1A1F1C al 50 % | fondo oscuro detrás de un modal |

## Reglas
- Espaciado en múltiplos de 8 (8, 16, 24, 32).
- Bordes redondeados de 12.
- Botones y celdas táctiles de 48 de alto como mínimo.
- Fuente del sistema. Títulos 22 en negrita, texto 16, secundario 14.
- Cada pantalla tiene estados de cargando, vacío y error.
