---
name: doc-bitacora
description: Usar al cerrar cada tarea para registrarla en la bitácora y en el plan.
---

1. Agregá una fila arriba de todo en `docs/proceso/bitacora.md`: fecha, tarea, qué se hizo, error encontrado, solución, commit.
2. Si no hubo error, poné "—". No inventes errores.
3. Marcá la tarea con `[x]` en `docs/proceso/plan-hitos.md`.
4. Proponé el mensaje de commit (`tipo: descripción`) y el comando:
   `git add . && git commit -m "<mensaje>"`
